مشروع Personality Quiz كامل

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح مجلد Personality-Quiz-Complete في Visual Studio Code.
3) افتح index.html.
4) شغّل Live Server.

الملفات:
- index.html الصفحة الرئيسية
- about.html عن الاختبار
- quiz.html الأسئلة
- result.html النتيجة
- contact.html فريق المشروع 
- style.css التصميم
- script.js التفاعل
- images/ الرسومات

ملاحظة:
الخط المستخدم Google Fonts، وسيعمل بخط بديل إذا لم يوجد اتصال بالإنترنت.
